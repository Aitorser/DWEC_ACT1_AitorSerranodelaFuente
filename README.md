# Actividad 1 — Desarrollo Web en Entorno Cliente (JavaScript)

Página web interactiva desarrollada con **HTML, CSS y JavaScript** (sin frameworks),
como Actividad 1 de la asignatura DWEC (Desarrollo Web en Entorno Cliente), del ciclo de
Desarrollo de Aplicaciones Web (DAW).

> Proyecto de aprendizaje. Lo mantengo público como muestra de mis fundamentos de
> desarrollo web en el lado del cliente.


## Qué demuestra

- Maquetación con **HTML5** y estilos con **CSS3**.
- Interactividad en el cliente con **JavaScript** (manipulación del DOM y manejo de eventos).
- Estructura de proyecto web sencilla y separada (estructura, estilos y lógica en archivos distintos).

## Tecnologías

- HTML5
- CSS3
- JavaScript
